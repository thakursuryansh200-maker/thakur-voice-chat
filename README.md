# THAKUR VOICE CHAT — Step 1

Starter Flutter UI prototype based on the supplied reference screens.

## Run
1. Install Flutter.
2. Run `flutter create .` inside this folder if platform folders are missing.
3. Replace the generated `lib/main.dart` with this project's `lib/main.dart`.
4. Run `flutter run`.

Step 1 includes:
- Home / Party screen
- Profile screen
- Message screen
- Agency Management screen
- Bottom navigation
- THAKUR VOICE CHAT branding

This is a UI prototype. Real login, voice rooms, wallet/coins, database, gifts and admin backend come in later steps.
